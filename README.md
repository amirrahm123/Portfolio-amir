# Amir Rahm – portfolio

Static one-page portfolio (`site/`) plus one Vercel function (`api/contact.js`) for the contact form.

- `npm run build` copies `site/` to `dist/`, which Vercel serves.
- The contact form needs `GMAIL_USER` and `GMAIL_APP_PASSWORD` set in the Vercel project.
- The previous React version lives on the `legacy-v1` branch.
