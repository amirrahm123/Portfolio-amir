# Project screenshots

Drop your real screenshots here. The file **basename** must match the `image`
field in `src/data/projects.ts` — the extension can be anything supported
(`.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, `.avif`). No code changes needed.

| Project              | Drop a file named           |
| -------------------- | --------------------------- |
| AmirBallBot          | `amirballbot.png` or `.gif` |
| ArikApp              | `arikapp.png`               |
| Eran Beker — Law Firm| `ebeker.png`                |
| Lotef — Pharmacy     | `lotef.png`                 |

Recommended aspect ratio ≈ **1280×860** (matches the card's reserved box, so
there's no layout shift). Until a file exists, a tidy tinted placeholder with
the project name is shown automatically.
