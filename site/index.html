Document AI for law firms

Reviews a real-estate deal file in under a minute (Hebrew, fictional data)

A sale agreement, a land registry extract and a bank letter: the documents a lawyer cross-checks line by line before a property deal. The AI reads them together, pulls out the key data with an exact quote for every item, and flags what doesn't match: a different sub-parcel, a swapped ID digit, a third-party warning note the contract never mentions, payments that don't add up. Every quote is checked against the document before it's shown, and the lawyer can ask the file questions in plain language.

  • Key data and red flags with a source for each, verified against the text
  • Click any source to see it highlighted in the document
  • Built the same way for leases, injury files or any document that repeats

A lead engine that runs every morning

AI agent and follow-up dashboard, in daily use

Built for my own business, and the same kind of system I build for offices that drown in enquiries and follow-ups. Each morning it searches Google Maps for law firms, clinics and venues, reviews every website (a technical check plus an AI design review of real screenshots), finds the contact details, and writes a personal message for each business. A dashboard then walks every lead through contact, follow-up reminders and replies, and a short email each morning lists who to call today.

  • Around 30 new leads a day, in Israel and in Munich
  • Websites, emails and mobile numbers checked against their source, nothing guessed
  • Follow-up reminders every 3 days, with call notes and history
  • Runs on its own on GitHub Actions; the dashboard is a private web page
